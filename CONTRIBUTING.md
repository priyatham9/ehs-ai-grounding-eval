# Contributing

## Running Tests

```bash
cd /path/to/ehs-ai-grounding-eval
python3 -m unittest discover -s tests -v
```

121 tests, no third-party dependencies beyond standard library, numpy and pandas. Tests run offline.

## Dependency Policy

This project uses Python 3.9 or later with:
- Standard library only
- numpy
- pandas

No other runtime dependencies. No requests, no embedding libraries, no LLM SDKs.

## Numbers in the Repository

Every number in the repository comes from:

1. **Committed scripts** that compute or verify results, or
2. **The corpus itself** (e.g., item counts, domain breakdown)

Specific rules:

- Results published in `results/` must be generated by `python3 -m grounding_eval.run_baselines` and committed with their generation command recorded
- Source verification figures come from `tools/verify_sources.py` and the dated report is committed in `corpus/verification/source_verification.json`
- Mock demonstration runs carry `MOCK_DEMONSTRATION_FIXTURE_NOT_RESULTS` in every artifact and are never published as real findings

## Synthetic Data

`synthetic/` contains a demonstration fixture generator. Rules:

- The mock adapter's output is labelled `MOCK_DEMONSTRATION_FIXTURE_NOT_RESULTS` in every artifact
- The loader never reads the mock config; tests only - it is for harness demonstration and infrastructure testing
- No number from the mock run may appear in documentation or be presented as a result
- See `synthetic/README.md` for details on how the fixture is generated

The benchmark itself is not synthetic: the 68 items and their sources are real.
