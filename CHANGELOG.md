## [Unreleased]

### Added
- Unsubmitted preprint draft (`docs/manuscript/manuscript.md`, IMRaD, author Priyatham Chimmani): corpus, task and scoring, retrieval arms, accuracy with cluster-bootstrap, Wilson and exact Clopper-Pearson intervals, risk-coverage, calibration (TF-IDF only), paired significance, citation-integrity checking and the quarantine, and limitations (no LLM arm run). Appendix A gives a source file and machine-readable locator for every number; `tools/check_manuscript.py` and `tests/test_manuscript.py` re-derive each one (and fail on an unsourced number in the prose). Appendix B marks the verification status of each reference: Brier, Naeini et al. and Guo et al., written from memory earlier, were checked and are confirmed (Naeini's first name and the Brier details come from the AAAI record and a secondary source respectively); Clopper-Pearson volume and pages, Lv and Zhai authors and the E-AURC attribution remain unverified and are marked. 8 new tests (README test count 204 -> 212). Not submitted or posted anywhere
- Paired significance between arms (`grounding_eval/significance.py`): exact McNemar test, paired cluster-bootstrap CI for the accuracy difference and Holm step-down correction across 10 comparisons (6 retriever pairs, 4 retrievers against random_floor) on the 63 factual items. Outputs `results/significance_pairwise.csv` / `.md`; methods note `docs/methodology.md` section 5c, results section in `docs/results.md`. No two retrievers differ significantly (at most 1 discordant item per pair, Holm p = 1.000); each is significantly below random_floor repeat 0 (Holm p 0.021 to 0.032), but BM25 is not significant on the weakest of the five repeats (raw p 0.058). 11 new tests (README test count 193 -> 204)
- Calibration metrics (`grounding_eval/calibration.py`): Brier score, equal-width-bin expected calibration error, reliability table, cluster-bootstrap CIs; the metrics reject confidences outside [0, 1]. Computed for `retrieval_tfidf` only (cosine, in [0, 1]): Brier 0.202 [0.182, 0.221] against 0.197 for a constant at the 27.0% accuracy, ECE 0.192 [0.128, 0.307] over 10 bins. Not computed for BM25, BM25+ and RRF (scores not on a probability scale) or random_floor and oracle (no confidence). Outputs `results/calibration_summary.csv` / `.md` and `calibration_reliability.csv`; methods note `docs/methodology.md` section 5b, results section in `docs/results.md`. 11 new tests (README test count 182 -> 193)
- `.zenodo.json` and `codemeta.json` (title, description, creators from `CITATION.cff`, MIT licence, keywords, related identifiers for the sibling repositories and the programme site; no DOI or ORCID) so a release is archived with correct metadata once Zenodo is linked; `CITATION.cff` gains `keywords`. `tools/check_citation.py` (stdlib, run by `.github/workflows/citation.yml`) checks the required CFF 1.2.0 fields and that `CITATION.cff`, `.zenodo.json`, `codemeta.json` and `LICENSE` agree on title, authors, keywords and licence. No release or tag created.
- Answer-or-abstain scoring (`grounding_eval/selective.py`): tie-aware risk-coverage points, AURC, E-AURC, selective accuracy at 25/50/75 percent coverage, cluster-bootstrap CIs; applied to the four retrievers' confidence scores in `results/selective_summary.csv` / `.md` and `results/selective_curves.csv` (AURC 0.564 TF-IDF, 0.571 BM25, 0.602 BM25+, 0.699 RRF against an uninformative 0.714 to 0.730). random_floor and oracle report no confidence and are n/a. Methods note with verified references in `docs/methodology.md` section 5a; results section in `docs/results.md`. 10 new tests (README test count 172 -> 182)
- Four regulatory-currency drafts in `corpus/quarantine/unverified.json` (`q-rc-hcs-001` to `-003`, `q-rc-rk-001`), each recording the amending Federal Register document that was fetched (91 FR 1695, 89 FR 81829, 88 FR 47254). They stay excluded from scoring because the current eCFR text could not be fetched to run `tools/verify_sources.py`; no scored count changes
- Two more non-LLM retrieval baselines in `grounding_eval/adapters/bm25plus.py`: `retrieval_bm25plus` (BM25+, k1=1.2, b=0.75, delta=1.0, non-negative IDF) and `retrieval_rrf` (reciprocal rank fusion, k=60, of the TF-IDF and Okapi BM25 rankings). Parameters were fixed in code at the published defaults before either was run; one configuration each, nothing tuned. Factual accuracy: BM25+ 27.0% [15.4, 40.0], RRF 27.0% [15.4, 40.0], against TF-IDF 27.0% and Okapi BM25 28.6% [17.2, 40.9]. Neither new arm beats the existing retrievers

## [0.1.0] - 2026-09-09

### Added
- Benchmark with 68 verified items (63 factual, 5 category-error) across 8 regulatory domains measuring whether AI answers are grounded in authoritative sources
- Complete minimal pairs (23) where items differ only in the entity asked about, to expose generic topical answers that fail the distinction
- Source verification framework verifying all 68 items against primary federal sources (eCFR) with anchor-text and paragraph-location checks
- Scoring harness with deterministic lexical scoring: UNSCORABLE, ABSTAINED, CORRECT, ADJACENT_SUBSTITUTION, OTHER_INCORRECT outcomes
- Three non-LLM baselines (random floor, TF-IDF retrieval, oracle ceiling) showing items discriminate and establishing baseline performance
- **No language model has been evaluated on this benchmark.** Baseline results are non-LLM only. Mock adapter provides labelled demonstration fixture.
