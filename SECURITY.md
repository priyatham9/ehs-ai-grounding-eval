# Security

We aim to respond to security reports within 14 days of receipt. The scope of this project is the code and the corpus (specifically, the text of each item).

Report security issues to the repository maintainers via a private security advisory rather than the public issue tracker.

## Supported scope

Security reports for:
- Code vulnerabilities in this repository
- Factual errors in corpus items (specifically, whether the item's text accurately reflects what the eCFR currently says)

Corrections to CFR citations are welcome as issues with a link to the relevant eCFR page and the current date of verification.

## Out of scope

- Matters unrelated to the code or corpus text
